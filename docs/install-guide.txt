TideTicker — macOS 菜单栏加密货币行情
作者 @rongcat · https://x.com/rongcat

系统要求
macOS 13 或以上。此安装包同时包含 Apple Silicon（arm64）与 Intel（x86_64）版本。
Intel Mac 的实际运行仍待真机验收。

安装
1. 如果已安装 TideTicker，请先从菜单栏退出旧版。
2. DMG：将磁盘映像中的 TideTicker.app 拖入旁边的 Applications（应用程序）文件夹。
   ZIP：解压后将 TideTicker.app 移入 Applications（应用程序）文件夹。
3. DMG 复制完成后先弹出磁盘映像；两种格式均从“应用程序”打开已安装的 TideTicker。
4. TideTicker 在菜单栏显示报价，没有 Dock 图标。点击报价可打开主窗口、立即刷新、管理显示与启动选项或退出。

首次打开
当前版本使用本地 ad-hoc 签名，尚未使用 Developer ID 签名及 Apple 公证，macOS 可能阻止首次打开。
仅在确认文件来源可信、愿意使用此版本时，先尝试打开应用，再前往“系统设置”→“隐私与安全性”，
找到关于 TideTicker 的拦截提示并选择“仍要打开”（Open Anyway），按系统提示确认。
如果系统明确提示应用包含恶意软件或已损坏，请停止使用，并向作者反馈完整提示。
Apple 官方说明：https://support.apple.com/102445

开始使用
新安装默认使用系统网络，显示 OKX 的 BTC、ETH USDT 永续合约标记价，无需账户或 API Key。
OKX 系统网络使用 WebSocket 主报价；5 秒是断线时的 REST 兜底间隔。物理直连及其他来源使用 REST 采样。
点击菜单栏报价，选择“显示主窗口”，可查看行情概览，并在“关注品种”“行情来源”“到价提醒”中调整配置。
现货报价与提醒使用最新成交价，USDT 永续和币本位永续使用标记价；不同市场不会混用。应用不执行交易或下单。
如需提醒，请在已安装的应用中允许通知，并在“系统设置”→“通知”中检查 TideTicker 的通知选项。
“登录时启动”可在应用菜单中管理；首次运行会尝试注册，如系统要求批准，请按提示确认。
请完成安装并从“应用程序”启动后，再设置通知和登录启动，避免直接从磁盘映像长期运行。

网络与数据
行情来自交易所官方公共 API，可用性取决于本地网络、代理配置与地区。
在“显示主窗口”→“行情来源”→“网络连接”中选择模式，再点击“测试连接”查看目录、代表报价、错误类别和建议。
系统网络：新安装默认选项，沿用 macOS 已配置的 HTTP / HTTPS / SOCKS / PAC 代理、DNS 与路由，
不固定使用 1.1.1.1。应用不代替用户配置系统代理。
物理直连：保留原有连接方式，显式禁用代理、绑定物理网卡，需要可用的物理 IPv4 网络，
并能直接访问 Cloudflare DNS-over-HTTPS 与所选交易所。

从早期测试版本升级时，如果旧配置缺少网络模式，会继续使用物理直连。如遇直连超时，或希望使用已配置的系统代理，
请手动选择“系统网络”，然后测试连接。切换模式立即保存并重连，切换交易所会保留当前网络模式。
重连时保留上次报价并按原数据时间判断过期；穿越类提醒先重新建立基准，重连期间的穿越不补发。
连接失败时显示错误，不自动切换网络模式或来源；过期报价会变灰并显示“!”。
若交易所返回 HTTP 403 / 451 等拒绝访问错误，应用会保留该错误，不绕过服务端访问限制。
